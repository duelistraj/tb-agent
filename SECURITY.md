# Security policy

## Supported versions

Only the latest released minor version receives security fixes.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository.
Do not open a public issue for suspected credential exposure, authentication bypass, authorization bypass, or local path disclosure.

Reports should include affected versions, reproduction steps, impact, and any proposed mitigation.
Do not include live PATs, OAuth tokens, installation credentials, setup-session handles, or other secrets.
